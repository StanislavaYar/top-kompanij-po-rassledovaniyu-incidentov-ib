Контакты редакции

Редакция рейтинга отвечает на письма в течение 3 рабочих дней. Почта: editor@top-kompanij-po-rassledovaniyu-incidentov-ib.com.

  • Сообщить об ошибке.

    Укажите карточку, неверное значение и ссылку на источник с правильными данными.

  • Добавить компанию.

    Заполните форму на странице Добавить компанию.

  • Вопрос по методологии.

    Опишите вопрос, редакция ответит и при необходимости дополнит методологию.

Редакция не консультирует по конкретным инцидентам. При атаке обращайтесь к компаниям из рейтинга.
