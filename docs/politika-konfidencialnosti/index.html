Политика конфиденциальности и использования cookie

Редакция: 12.10.2026

Политика описывает, какие персональные данные получает сайт рейтинга IR-компаний и как редакция их использует. Политика составлена с учетом Федерального закона № 152-ФЗ "О персональных данных".

Какие данные получает сайт

Сайт получает персональные данные только из писем, которые пользователь отправляет редакции. Форма заявки на странице "Добавить компанию" открывает почтовую программу пользователя и не передает данные на сервер сайта.

Редакция получает из письма 3 типа данных:

  • адрес электронной почты отправителя;
  • имя и должность, если отправитель их указал;
  • название компании и сведения о ее услугах.

Как используются данные

Редакция использует данные из писем только для ответа отправителю, проверки заявки компании и исправления ошибок в рейтинге. Редакция не передает данные третьим лицам и не использует их для рассылок.

Письма хранятся в почтовом ящике редакции не дольше 3 лет с момента получения. После этого письма удаляются.

Cookie

Сайт не использует cookie и не подключает счетчики посещаемости на дату редакции политики. Если редакция подключит счетчики, политика получит список cookie, их назначение и срок хранения.

Права пользователя

Пользователь может запросить сведения о своих данных, их уточнение или удаление по статье 14 152-ФЗ. Запрос направляется на почту editor@top-kompanij-po-rassledovaniyu-incidentov-ib.com.

Редакция отвечает на запрос в течение 10 рабочих дней. Ответ содержит перечень данных или подтверждение их удаления.

Изменения политики

Редакция обновляет политику при изменении состава собираемых данных. Дата редакции стоит в начале страницы.
