# Рейтинг IR-компаний

Статический сайт: рейтинг компаний по расследованию инцидентов ИБ и гайды по теме.

## Структура

| Путь | Что лежит |
| --- | --- |
| `content/` | Тексты страниц в Markdown. Комментарии `<!-- -->` задают компонент верстки для следующего блока. |
| `data/companies.json` | Параметры компаний для карточек и ссылки на источники. |
| `assets/` | Стили, скрипт интерфейса, шрифты, изображения. |
| `tools/` | Сборка (`build.pl`) и служебные скрипты: скриншоты, WebP, иконки, проверки. |
| `docs/` | Готовый сайт. Публикуется через GitHub Pages (ветка `main`, папка `/docs`). |

## Сборка

```bash
bash build.sh
```

Скрипт пересоздает `docs/`: собирает страницы из `content/` и копирует `assets/`, favicon и служебные файлы.

## Проверки

```bash
perl tools/check.pl         # JSON-LD, внутренние ссылки, alt
perl tools/domain-links.pl  # ссылки на сайты компаний на главной
perl tools/card-words.pl    # объем карточек компаний
perl tools/publish-audit.pl # файлы в docs/ без ссылок со страниц
```

## Индексация

Сайт закрыт от индексации (`noindex, nofollow`). Порядок открытия описан в `README-launch.md`.
